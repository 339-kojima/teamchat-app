# 機能一覧・今回作らないもの

## 機能一覧

| ID | 機能 | 内容 |
|:--|:--|:--|
| F-01 | アカウント登録 | 表示名・メールアドレス・パスワードで社員が登録する |
| F-02 | ログイン・ログアウト | メールアドレスとパスワードでログインし、ログアウトする |
| F-03 | チャンネル一覧 | 閲覧可能なチャンネルの名前、説明、公開範囲、作成者を表示する |
| F-04 | チャンネル作成 | 名前・説明・公開範囲を指定して作成する。作成者は自動的にメンバーになる |
| F-05 | チャンネル閲覧・投稿 | 公開チャンネルはログイン社員全員、非公開チャンネルはメンバーが閲覧・投稿する |
| F-06 | チャンネル編集・削除 | 作成者だけが名前・説明を編集し、チャンネルを削除する |
| F-07 | プライベートチャンネルのメンバー管理 | 作成者がメンバーを追加・削除する。作成者自身はメンバーである |
| F-08 | メッセージ編集・削除 | 投稿者が自分のメッセージを編集・削除する。編集済み表示と削除跡を残す |
| F-09 | スレッド返信 | メッセージに返信し、親メッセージに返信件数を表示する |
| F-10 | メッセージ検索 | 閲覧可能なチャンネルに限って検索し、チャンネル・投稿者・日時とともに結果を表示する |
| F-11 | 公開読み取りAPI | 認証なしで公開チャンネル一覧と公開チャンネルのメッセージ一覧を提供する |
| F-12 | 初期データ | 仕様書記載の3アカウント、4チャンネル、所定条件を満たすメッセージを用意する |

## 今回作らないもの

| 対象 | 理由 |
|:--|:--|
| 新着メッセージの自動表示 | 画面を開き直して確認できればよい |
| 通知（メール・スマートフォン） | まず社内で使い始められる形を優先 |
| 1対1のダイレクトメッセージ | チャンネルでの会話に絞る |
| ファイル・画像添付 | 文章のやり取りに絞る |
| メッセージへのリアクション | 会話を優先 |
| 未読・既読管理 | 会話を優先 |
| 管理者による全体管理 | 運用が固まってから検討 |
| スマートフォン向け表示 | PCブラウザを対象とする |
