# 権限・ルーティング・公開API設計

## 権限マトリクス

| 機能 | 未ログイン | ログイン社員 | 対象チャンネル作成者 | 作成者以外のプライベートメンバー | 対象メッセージ投稿者 |
|:--|:--:|:--:|:--:|:--:|:--:|
| F-01 アカウント登録 | ○ | △ | △ | △ | △ |
| F-02 ログイン・ログアウト | △ | △ | △ | △ | △ |
| F-03 チャンネル一覧 | × | △ | △ | △ | △ |
| F-04 チャンネル作成 | × | ○ | ○ | ○ | ○ |
| F-05 チャンネル閲覧・投稿 | × | △ | ○ | ○ | △ |
| F-06 チャンネル編集・削除 | × | △ | ○ | × | × |
| F-07 プライベートチャンネルのメンバー管理 | × | × | △ | × | × |
| F-08 メッセージ編集・削除 | × | △ | △ | △ | ○ |
| F-09 スレッド返信 | × | △ | ○ | ○ | △ |
| F-10 メッセージ検索 | × | △ | △ | △ | △ |
| F-11 公開読み取りAPI | ○ | ○ | ○ | ○ | ○ |
| F-12 初期データ | × | × | × | × | × |

△ の条件：

- F-01：未ログイン社員の自己登録は可能。ログイン中の社員が追加登録できるかは資料に指定がない。
- F-02：未ログイン時はログイン、ログイン中はログアウトが可能。
- F-03：ログイン社員は公開チャンネルと、自分が参加しているプライベートチャンネルを一覧できる。非メンバーにはプライベートチャンネルの存在も見せない。
- F-05：ログイン社員は公開チャンネルを閲覧・投稿できる。プライベートチャンネルでは、そのチャンネルの作成者またはメンバーに限る。投稿者列も、現在そのチャンネルを閲覧できることが条件。
- F-06：対象チャンネルの作成者に限る。
- F-07：プライベートチャンネルの作成者に限る。メンバー追加・削除ができるが、作成者をメンバーから外す操作はできない（確認事項の回答）。
- F-08：対象メッセージの投稿者本人に限る。投稿者以外のログイン列は、自分の投稿を対象にする場合のみ可能。
- F-09：対象チャンネルの閲覧権限がある場合に返信できる。投稿者列も、対象チャンネルの閲覧権限が残っていることが条件。
- F-10：ログインが必要で、本人が閲覧できるチャンネル内のメッセージだけを検索する。

### マトリクスだけでは表せない範囲の保護

F-10 と F-11 の記号は、機能の入口を使えるかどうかを示すだけで、返すレコードの範囲までは表しません。○や△が付いていても、以下の絞り込みを各リクエストで行います。

- **F-10 メッセージ検索**：ログインを確認したうえで、検索対象を公開チャンネルと本人が参加しているプライベートチャンネルに限定してから本文を検索します。非参加プライベートチャンネルの本文・名前・検索結果件数を返さず、削除済みメッセージも結果から除外します。
- **F-11 公開読み取りAPI**：認証なしで利用できますが、チャンネル一覧は公開チャンネルだけに絞ります。メッセージ一覧も指定された公開チャンネルの未削除メッセージだけを返します。非公開チャンネルと存在しないIDには同じ404を返し、書き込み用エンドポイントは設けません。

「ログイン社員」は特別な関係を持たない基本のログイン状態を表し、右側の役割列は操作対象のチャンネルまたはメッセージとの関係を表す。役割は重複し得る。チャンネル作成者はそのチャンネルのメンバーでもある。F-12 はシーダーによる初期データ作成であり、利用者が画面から実行する機能ではない。

## Webルーティング

| Method | Path | 認証・権限 | 処理 |
|:--|:--|:--|:--|
| GET | `/register` | 不要（ログイン中の表示可否は未確定） | 登録画面 |
| POST | `/register` | 不要（ログイン中の利用可否は未確定） | アカウント登録後、ログイン画面へ移動 |
| GET | `/login` | 不要 | ログイン画面 |
| POST | `/login` | 不要 | 認証成功後、チャンネル一覧へ移動 |
| POST | `/logout` | 必要 | ログアウト |
| GET | `/channels` | 必要 | 公開チャンネルと閲覧可能なプライベートチャンネルの一覧 |
| GET | `/channels/create` | 必要 | チャンネル作成画面 |
| POST | `/channels` | 必要 | チャンネル作成。作成者をメンバーに含め、成功後はチャンネル一覧へ移動 |
| GET | `/channels/{channel}` | 必要・閲覧権限 | チャンネル、メッセージ一覧、投稿欄 |
| GET | `/channels/{channel}/edit` | 必要・作成者 | 編集・削除画面 |
| PUT | `/channels/{channel}` | 必要・作成者 | チャンネル名・説明を更新し、成功後はチャンネル一覧へ移動 |
| DELETE | `/channels/{channel}` | 必要・作成者 | チャンネル名による確認後、チャンネルと所属メッセージ・返信・メンバー情報を削除し、成功後はチャンネル一覧へ移動 |
| GET | `/channels/{channel}/members` | 必要・プライベートチャンネル作成者 | メンバー管理画面。表示名またはメールアドレスでの検索入力を受け付ける |
| POST | `/channels/{channel}/members` | 必要・プライベートチャンネル作成者 | 指定ユーザーを追加 |
| DELETE | `/channels/{channel}/members/{user}` | 必要・プライベートチャンネル作成者 | 指定メンバーを削除。作成者は削除対象にできない |
| POST | `/channels/{channel}/messages` | 必要・閲覧権限 | チャンネルへのメッセージ投稿 |
| PUT | `/messages/{message}` | 必要・投稿者本人 | メッセージまたは返信をその場編集 |
| DELETE | `/messages/{message}` | 必要・投稿者本人 | 論理削除（`body = NULL`, `deleted_at` 設定） |
| GET | `/messages/{message}/thread` | 必要・閲覧権限 | チャンネル投稿を親とするスレッドと返信を表示 |
| POST | `/messages/{message}/replies` | 必要・閲覧権限 | チャンネル投稿への返信。返信への返信は不可 |
| GET | `/search?q={keyword}` | 必要 | 閲覧可能なチャンネルのメッセージ本文を検索 |

権限のないプライベートチャンネルは、存在しないチャンネルと同じ404として扱い、名前や内容を返さない。認証が必要な画面への未ログインアクセスはログイン画面へ誘導する。

## 公開読み取りAPI

全エンドポイントは認証不要の読み取り専用JSON API。バージョン接頭辞は `/api/v1`、ページングなし（Q-11）、メッセージは `created_at` の古い順。リクエスト本文・認証情報は不要。

| Method / Path | 入力 | 成功時の内容 |
|:--|:--|:--|
| GET `/api/v1/channels` | なし | 公開チャンネルの `id`, `name`, `description` の一覧。 |
| GET `/api/v1/channels/{channel}/messages` | パス値 `channel`: チャンネルID | 指定された公開チャンネルの未削除メッセージ。投稿と返信を同じ配列で返し、返信は `parent_id` で親投稿を示す。投稿者名、本文、投稿時刻、編集時刻を含める。 |

成功レスポンス例（値は形式説明用）：

`GET /api/v1/channels`

```json
{
  "data": [
    {
      "id": 2,
      "name": "開発",
      "description": "開発に関する相談と報告"
    }
  ]
}
```

`GET /api/v1/channels/2/messages`

```json
{
  "data": [
    {
      "id": 101,
      "parent_id": null,
      "author": "鈴木 花子",
      "body": "おはようございます。リリース日程を今週中に決めましょう。",
      "created_at": "2026-08-17T09:12:00+09:00",
      "edited_at": null
    },
    {
      "id": 102,
      "parent_id": 101,
      "author": "佐藤 太郎",
      "body": "承知しました。担当タスクをまとめます。",
      "created_at": "2026-08-17T09:20:00+09:00",
      "edited_at": "2026-08-17T09:24:00+09:00"
    }
  ]
}
```

エラー応答はJSON形式とし、内部の例外情報や非公開情報は含めない。

| HTTP status | 条件 | 応答例 |
|:--|:--|:--|
| 404 Not Found | 指定IDのチャンネルが存在しない、またはプライベート（同一応答、Q-10） | `{"error":{"code":"not_found","message":"チャンネルが見つかりません。"}}` |
| 405 Method Not Allowed | 読み取り以外のHTTPメソッド | `{"error":{"code":"method_not_allowed","message":"このAPIは読み取り専用です。"}}` |
| 500 Internal Server Error | 予期しないサーバーエラー | `{"error":{"code":"internal_error","message":"サーバーエラーが発生しました。"}}` |

一覧に該当データがない場合は `200 OK` と `{"data":[]}` を返す。削除済みメッセージは `deleted_at` が設定されている行として除外する。非公開チャンネルの一覧・名前・メッセージは一切返さない。

## APIに関する未決事項

削除済み親メッセージに付いた未削除返信は、返信行自体を返すと `parent_id` の参照先が応答から欠ける。親を含めると「削除されたメッセージはAPIに含めない」という回答に反する。返信も除外するか、別の形で返すかは確認事項で決める。
