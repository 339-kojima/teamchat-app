# 受け入れ条件・テスト観点

## 受け入れ条件

各条件はブラウザで操作して確認する。

### 1. 認証

| ID | 受け入れ条件 |
|:--|:--|
| AC-1-1 | 未ログインまたはログイン中の社員が表示名・未登録メールアドレス・8文字以上のパスワードを登録すると、ログイン画面へ移動する。 |
| AC-1-2 | 登録済みメールアドレス、254文字を超えるメールアドレス、形式不正のメールアドレス、または8文字未満のパスワードで登録すると、該当項目にエラーが表示されて登録されない。 |
| AC-1-3 | 正しいメールアドレスとパスワードでログインするとチャンネル一覧が開き、ログアウトするとログイン画面へ戻る。 |

### 2. チャンネル

| ID | 受け入れ条件 |
|:--|:--|
| AC-2-1 | 公開またはプライベートを選んでチャンネルを作成すると、成功後にチャンネル一覧へ移動し、作成したチャンネルが閲覧範囲に応じて表示される。 |
| AC-2-2 | 同じ公開範囲に同名チャンネルを作成すると、チャンネル名のエラーが表示されて作成されない。 |
| AC-2-3 | 作成者が名前・説明を編集すると変更が一覧に反映され、公開範囲は変わらない。 |
| AC-2-4 | 作成者が確認欄にチャンネル名を入力して削除すると、一覧からチャンネルが消え、そのチャンネルのメッセージと返信も開けなくなる。 |

### 3. メンバー管理

| ID | 受け入れ条件 |
|:--|:--|
| AC-3-1 | プライベートチャンネルの作成者が社員を追加すると、その社員の一覧にチャンネルが現れ、チャンネルを開いて投稿できる。 |
| AC-3-2 | 作成者がメンバーを外すと、その社員の一覧からチャンネルが消えて直接開けなくなり、作成者はメンバーに残る。 |
| AC-3-3 | 作成者以外がメンバー管理画面を開こうとすると、404になりメンバー情報は表示されない。 |

### 4. メッセージ

| ID | 受け入れ条件 |
|:--|:--|
| AC-4-1 | 閲覧できるチャンネルにメッセージを投稿すると、本文・投稿者・投稿時刻が表示され、新しい投稿が下に並ぶ。 |
| AC-4-2 | 投稿者が自分のメッセージまたは返信をその場で編集すると「編集済み」が表示され、別の利用者は編集・削除できない。 |
| AC-4-3 | 投稿者が自分のメッセージまたは返信を削除すると、本文が削除済み表示に変わり、投稿者・投稿時刻・親投稿の返信件数と他の返信が残る。 |

### 5. スレッド

| ID | 受け入れ条件 |
|:--|:--|
| AC-5-1 | メッセージの返信を開くと、親メッセージと返信がまとまって表示され、返信件数が実際の返信数と一致する。 |
| AC-5-2 | スレッドから返信すると親メッセージの下に表示され、削除済みの親メッセージにも返信を追加できる。 |
| AC-5-3 | 返信に対して返信を送ろうとしても、返信として追加されない。 |

### 6. 検索

| ID | 受け入れ条件 |
|:--|:--|
| AC-6-1 | メッセージまたは返信の本文の一部を検索すると、一致した閲覧可能な内容とチャンネル名・投稿者・日時が表示され、結果からチャンネルまたはスレッドを開ける。 |
| AC-6-2 | 閲覧できないプライベートチャンネルだけにある語を検索すると、そのチャンネルの名前・本文・結果の存在が表示されない。 |
| AC-6-3 | 空白と改行だけのキーワードで検索すると、空欄として入力エラーが表示される。 |

### 7. 公開API

| ID | 受け入れ条件 |
|:--|:--|
| AC-7-1 | ログインせず公開チャンネル一覧APIを開くと、JSONで公開チャンネルだけが返る。 |
| AC-7-2 | ログインせず公開チャンネルのメッセージAPIを開くと、未削除メッセージが古い順のJSONで返り、削除済み親の返信は親なしで `parent_id` を保って返る。 |
| AC-7-3 | プライベートチャンネルと存在しないIDのAPIを開くと同じ404 JSONになり、読み取り以外のメソッドではデータが変更されない。 |
